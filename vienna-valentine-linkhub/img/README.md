# Images

Drop files here with these exact names and the site picks them up automatically.

| File         | Used for                | Recommended                          |
|--------------|-------------------------|--------------------------------------|
| `avatar.jpg` | The circular portrait   | Square, 480×480 or larger, under 250 KB |

If `avatar.jpg` is missing, the page falls back to the gold **VV** monogram —
the layout is designed to look finished either way, so there is never a broken
image.

Keep files small. These load on a phone over mobile data, straight off an
Instagram tap, and every 100 KB is a chance to lose someone before the page
paints.
